# Перемикач для булевих полів (Toggle Switch for Boolean Fields)

![EspoCRM 9.0+](https://img.shields.io/badge/EspoCRM-9.0%2B-2f6bb3)
![PHP 8.3+](https://img.shields.io/badge/PHP-8.3%2B-777bb4)
![Мови](https://img.shields.io/badge/мови-англійська%20%7C%20українська-4c9a2a)

[English](README.md) | **Українська**

Розширення для EspoCRM, яке перетворює булеві поля на зрозумілі перемикачі УВІМК./ВИМК. з вашим текстом, іконками та стандартними кольорами EspoCRM. За бажанням значення зберігається одним кліком прямо на сторінці запису та у списках.

---

## Навіщо це потрібно

Маленькі прапорці легко пропустити. Коли команда працює з багатьма налаштуваннями «увімк./вимк.», погодженнями чи робочими позначками, перемикач одразу показує поточний стан і зменшує кількість помилок під час введення даних. Розширення змінює лише вигляд і поведінку булевих полів в інтерфейсі. Збережені значення та зміст ваших полів залишаються незмінними.

## Можливості

- **Відображення у вигляді перемикача** для будь-якого булевого поля; вмикається окремо для кожного поля в налаштуваннях поля.
- **Власний текст** для станів ТАК і НІ, наприклад *Затверджено / Не затверджено*, *Активний / Заблокований* або *УВІМК. / ВИМК.*
- **Іконки** для станів ТАК і НІ з бібліотеки іконок EspoCRM, з пошуком. Можна показувати іконку разом із текстом або лише іконку.
- **Стандартні кольори EspoCRM**: Звичайний, Успішно, Небезпека, Застереження, Інформація та Первинний. Вибираються з того самого меню кольорів, що й для варіантів полів-списків. Кольори відповідають темі користувача, зокрема темі «Темна».
- **Три розміри**: Малий, Середній і Великий.
- **Швидке редагування (збереження по кліку)**: один клік по перемикачу одразу зберігає значення — на сторінці запису та прямо у списках.
- **Попередній перегляд** у налаштуваннях поля, який оновлюється під час зміни параметрів.
- **Враховує правила доступу EspoCRM**: права ролей, права на рівні полів, поля лише для читання, динамічну логіку та *Перевірку дублікатів при оновленні*.
- **Зручно для клавіатури й екранних читачів**: перемикач — це справжній прапорець із роллю `switch`, тож на нього можна перейти клавішею Tab і перемкнути клавішею Пробіл.
- **Англійська та українська** мови інтерфейсу вже включені.
- **Жодних змін у базі даних** і жодного серверного коду. Після видалення всі поля знову стають звичайними прапорцями.

## Встановлення

1. Завантажте останній пакет розширення (`.zip`) зі сторінки [Releases](../../releases).
2. В EspoCRM перейдіть до **Адміністрування → Розширення**.
3. Натисніть **Завантажити**, виберіть завантажений файл і натисніть **Встановити**.
4. Відкрийте **Адміністрування → Очистити кеш**.
5. Оновіть сторінку в браузері.

Розширення містить лише клієнтський код, переклади та метадані. Воно не змінює базу даних і не має PHP-класів.

### Оновлення

Нову версію встановлюють так само. Налаштування полів зберігаються.

## Налаштування

Відкрийте **Адміністрування → Менеджер сутностей → (ваша сутність) → Поля** і виберіть поле типу **Булевий тип**. Розширення додає такі параметри:

| Параметр | Що робить | За замовчуванням |
|---|---|---|
| **Відображати як перемикач** | Показує поле як перемикач замість прапорця. Якщо вимкнено, поле залишається звичайним прапорцем. | Вимкнено |
| **Швидке редагування (збереження по кліку)** | Клік по перемикачу одразу зберігає значення — на сторінці запису та у списках. | Вимкнено |
| **Перемикач: розмір** | Малий, Середній або Великий. | Середній |
| **Перемикач: текст ТАК** | Текст усередині перемикача, коли значення ТАК. | «Так» мовою користувача |
| **Перемикач: іконка ТАК** | Іконка перед текстом ТАК. Вибирається з бібліотеки іконок EspoCRM; кнопка **Нема** прибирає іконку. | Без іконки |
| **Перемикач: колір ТАК** | Один зі стандартних кольорів EspoCRM. | Успішно |
| **Перемикач: текст НІ** | Текст усередині перемикача, коли значення НІ. | «Ні» мовою користувача |
| **Перемикач: іконка НІ** | Іконка перед текстом НІ. | Без іконки |
| **Перемикач: колір НІ** | Один зі стандартних кольорів EspoCRM. | Звичайний |
| **Перемикач: попередній перегляд** | Попередній перегляд обох станів із поточними параметрами. Звідси нічого не зберігається. | |

Натисніть **Зберегти**. Новий вигляд одразу застосовується для всіх користувачів.

> Щоб розмістити поле на сторінках і у списках, використовуйте **Адміністрування → Менеджер макетів**, як зазвичай. Для деяких сутностей (наприклад, Контрагентів) нове поле також треба додати до макетів **Фільтри пошуку** та **Масове оновлення**, щоб воно там з'явилося.

## Як це працює

### Де з'являється перемикач

| Місце | Поведінка |
|---|---|
| Сторінка запису | Перемикач показує поточне значення. Зі швидким редагуванням клік зберігає значення. Без нього редагуйте, як зазвичай, через іконку олівця EspoCRM. |
| Форма редагування, вбудоване редагування, масове оновлення | Перемикач працює як поле форми. Нічого не зберігається, доки ви не натиснете **Зберегти**. |
| Списки | Компактні перемикачі. Зі швидким редагуванням клік зберігає значення цього рядка. Без нього перемикач лише показує значення, бо списки EspoCRM не мають власного вбудованого редагування. |
| Фільтри пошуку | Без змін. Залишається стандартний фільтр Так/Ні. |
| Поля без цього параметра | Без змін, звичайні прапорці. |

У списках розмір Великий показується як Середній, щоб рядки залишалися компактними.

### Швидке редагування (збереження по кліку)

Перемикач можна натиснути, лише якщо виконано всі умови; інакше він показується заблокованим:

- користувач має право редагувати запис (права ролі);
- користувач має право редагувати це поле (права на рівні полів);
- поле не має позначок **Лише для читання** чи **Тільки для читання після створення** і не стало доступним лише для читання через динамічну логіку;
- для поля не ввімкнено **Вимкнути вбудоване редагування**.

Коли іконка олівця більше не потрібна, вона для цього поля ховається.

Остаточне рішення завжди за сервером, тож без відповідних прав нічого змінити не можна:

- **Права у списках.** Списки EspoCRM завантажують лише видимі колонки. Для ролей із рівнем доступу «команда», для сутностей із *Multiple Assigned Users* (кількома відповідальними) та для *Collaborators* (співавторів) браузер не завжди може заздалегідь визначити, чи можна редагувати рядок. У таких випадках перемикач можна натиснути, а рішення ухвалює сервер. Якщо сервер відмовляє, перемикач повертається назад, а EspoCRM показує повідомлення **У доступі відмовлено**.
- **Перевірка дублікатів при оновленні.** Якщо для сутності ввімкнено цей параметр і запис має можливі дублікати, після кліку з'являється стандартне вікно EspoCRM *«Запис, який ви створюєте, може вже існувати»* — так само, як під час збереження зі сторінки запису. **Зберегти** записує нове значення; **Скасувати** або закриття вікна повертає перемикач назад.
- **Будь-яка інша помилка.** Перемикач повертається назад, а EspoCRM показує своє стандартне повідомлення про помилку.

Зміни, зроблені кліком, зберігаються як будь-яке інше редагування. Вони з'являються в стрічці, якщо для поля ввімкнено **Аудитоване**.

### Текст, іконки та мови

- **Порожній текст** показує «Так» / «Ні» мовою кожного користувача. Якщо вибрано іконку, а текст порожній, показується лише іконка.
- **Поширені слова перекладаються автоматично.** Якщо ввести одне з цих слів, користувачі бачитимуть його своєю мовою: Yes, No, On, Off, ON, OFF, YES, NO, Active, Inactive, Enabled, Disabled, Approved, Not Approved. Слова, які вже є мітками сутності або глобальними мітками EspoCRM, теж перекладаються. Будь-який інший текст показується так, як його введено.
- **Ширина перемикача однакова** в обох станах, тож списки не «стрибають», коли значення змінюються.

### Кольори

Шість кольорів — це стандартні стилі EspoCRM: **Звичайний** (сірий), **Успішно** (зелений), **Небезпека** (червоний), **Застереження** (помаранчевий), **Інформація** та **Первинний**. Вони беруться з активної теми, тому перемикач пасує до будь-якої теми EspoCRM, зокрема до теми «Темна».

## Сумісність

- Розширення задає типовий вигляд для булевих полів. Поля, які вже мають власний вигляд (view) у метаданих, зберігають його.
- Якщо інше розширення теж замінює типовий вигляд булевих полів, діє те, що має вищий порядок модуля (module order). У цього розширення порядок 30.

## Видалення

Перейдіть до **Адміністрування → Розширення** і натисніть **Видалити** для цього розширення. Усі булеві поля знову стануть звичайними прапорцями, а значення полів не зміняться. Налаштування перемикачів залишаються у визначеннях полів (без використання), тож після повторного встановлення ваша конфігурація повернеться.

## Переклади

Англійська та українська мови вже включені. Щоб додати мову, скопіюйте `custom/Espo/Modules/ToggleSwitch/Resources/i18n/en_US` у папку з кодом мови EspoCRM (наприклад, `de_DE`), перекладіть значення (ключі та заповнювачі, як-от `{user}`, залиште без змін) і очистьте кеш.
